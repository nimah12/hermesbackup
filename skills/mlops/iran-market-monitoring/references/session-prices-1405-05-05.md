## Key Lessons from This Session

1. **Unit confusion is common** — mesghal.com shows Rial but labels "تومان"
2. **Date matters** — initially reported 1403 instead of 1405
3. **IranJib is most reliable** for live Iranian market data (Playwright works well)
4. **Multiple sources needed** — single-source prices can be stale/wrong
5. **Telegram t.me/channel works** with Playwright for public channels
6. **Silent cron jobs** — only alert on threshold breach
7. **User forbids Hermes config changes** — don't touch model.context_length, agent.max_turns, etc.
